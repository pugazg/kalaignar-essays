# அச்சு உரை

# குடும்பத்தின் நல்விளக்கு

முதல்வர்

டாக்டர் கலைஞர்

மு. கருணாநிதி

தமிழ்நாடு குடும்பநலத்துறை

வெளியீடு

## அச்சு அல்லாத / physical-copy marks

- மேற்பகுதியில் நீல மை கையெழுத்து.
- தலைப்புக்குக் கீழ்புறத்தில் செவ்வக / மை நூலக முத்திரை.
- கீழ்ப்பகுதியில் பெரிய வட்ட நூலக முத்திரை; அச்சு வெளியீட்டு வரியின் ஒரு பகுதியை மேற்படுகிறது.
- foxing / வயதுச்சுவடுகள்.
