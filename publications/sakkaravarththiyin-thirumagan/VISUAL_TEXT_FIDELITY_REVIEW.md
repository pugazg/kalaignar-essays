# Visual text fidelity review — சக்கரவர்த்தியின் திருமகன்

## Purpose

This is a second, stricter layer above the earlier source transcription / `VERIFIED` workflow.

The controlling source is `TVA_BOK_0065662_சக்கரவர்த்தியின்_திருமகன்.pdf` (83 scans; recorded SHA-256 `5d7f8404a53c0766df896ddedf9978a3fd31f97b8e98625b70a93366412eb90d`).

For this pass, each physical scan is reopened and compared directly with its page-level Markdown. The check covers every readable printed word, word boundary/spacing, punctuation mark, quotation mark, numeral, date, heading, paragraph boundary and cross-page continuation. Physical-copy marks remain separate from printed text.

**Important:** this review is deliberately batch-based. Only scans explicitly marked below as `FIDELITY-PASS` or `CORRECTED` count as completed. Any earlier repository-wide `strict-pass` claim is superseded by this staged record.

## Verdicts

- `FIDELITY-PASS` — every readable printed token checked against the scan; no discrepancy found.
- `CORRECTED` — one or more discrepancies in the original transcription were corrected from scan pixels and propagated to dependent source-facing files; a later staged pass may revalidate an already-propagated correction.
- `NEEDS-PIXEL-REVIEW` — at least one glyph/mark remains genuinely unresolved after enlargement; context is not used to guess.
- `PENDING` — not yet processed in this stricter pass.
