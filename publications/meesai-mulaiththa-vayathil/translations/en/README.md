## Translation baseline

- translate paragraph by paragraph from the strict-reviewed Tamil assembly;
- retain direct address, commands, rhetorical questions, repetition, sarcasm, ridicule, emotional force and literary imagery;
- preserve source quotation/speaker boundaries and verse lineation where present;
- retain source-page comments using `<!-- Tamil source: scan N / printed N -->`;
- normal English punctuation spacing is allowed, but rhetorically meaningful punctuation must remain;
- do not silently identify or expand unexplained literary/cultural references from memory or outside sources;
- do not import another publication's lexical choices merely for consistency;
- exact source `உடன்பிறப்பே` is always **`Udanpirappē`**, direct salutation **`Udanpirappē,`**, if that exact form occurs.
