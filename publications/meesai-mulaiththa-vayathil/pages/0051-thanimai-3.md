# அச்சு உரை

## அச்சிடப்பட்ட ஓடுதலைப்பு

மீசை முளைத்த வயதில்

ஆண் : கட்டிலறைக்கா வந்திருக்கிறாய்; கண்
      உதிர்ந்தவளே! நன்றாகப் பார்! இது
      கட்டிலறையா? காராக்கிரகத்தின்
      காவலறையடி!

பெண் : ஆமாம் - இந்த அறையில் என்னைத் தவிர
       உமக்கு இன்பமான பொருள் எது துரையே!
       வாரும், சினம் கொண்ட பாம்புகள் போல்
       பின்னிக் கொள்வோம்... ஏன் தயக்கம்?

ஆண் : பேசாதே!

பெண் : கனியே வருகிறது - சுவைத்திட
       மறுக்கிறீர். மலரே வருகிறது -
       முகர்ந்திடேன் என்கிறீர். இன்பமே
       வருகிறது- எட்டி நில் என்கிறீர். நீர்
       அதிசயமான கள்ளை - புதுமையான
       வண்டு - விசித்திரமான மனிதர்.

ஆண் : இப்போது நீ என்னதான் சொல்கிறாய்?

பெண் : எதைச் சொன்னால் நீர் ஆசையோடு
       கேட்பீர்?.... “சங்கத் மொழி பேசும் உம்
       குழந்தைச் செல்வங்கள், ‘அப்பா எப்ப
       வரும் ஆத்தா?’ என்று உமது தாயாரிடம்
       சிணுங்கி அழுவார்களே; அதைச்
       சொல்லவா?

ஆண் : அய்யோ - போதும் நிறுத்து!

பெண் : தலையணையைக் கண்ணீரால்
       குளிப்பாட்டும் உம் மனைவியின்
