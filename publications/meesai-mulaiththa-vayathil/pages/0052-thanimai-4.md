# அச்சு உரை

## அச்சிடப்பட்ட ஓடுதலைப்பு

கலைஞர் மு. கருணாநிதி

நிலையைச் சொல்லவா? அதைக்
கேட்பீரா?

ஆண் : வேண்டாமடி, வேண்டாம்!

பெண் : பிறகென்ன, பழைய நினைவுகளைச்
       சொல்லட்டுமா? மரணப்படுக்கையில்
       உமது முதல் மனைவி பத்மாவதி -
       ‘கடைசி யாகத் துடிக்கும் என் உதட்டில்
       ஒரு முத்தங்கள் கொடுங்கள் தான்” என்று
       கேட்பதற்கு முன் பெற்றுக்கொண்டாளே....

       அதை....

ஆண் : அய்யோ... வேண்டாம்.... நீ போயேன்!

பெண் : உமது குடும்பத்தார் - தாய், மனைவி,
       சகோதரிகள்.... குழந்தைகள்... உழுவலன்பு
       பூண்ட நண்பர்கள்... உமது நலமே தன்னல
       மாய்க் கொண்டிருந்த தந்தை.....

ஆண் : சொன்னால் கேள்! போதும் நிறுத்து!

பெண் : இதெல்லாம் பிடிக்காவிட்டால் உமக்கு
       மிகவும் இனிப்பான சேதி சொல்லுகிறேன்;
       இந்த நாடு இருக்கிறதே - இது ஒரு
       அடிமை பூமி. இதை விடுவிக்க
       உண்மையான தொண்டர்களும்,
       நேர்மையான தலைவர்களும் எத்தனை
       பேர் வேண்டும் தெரியுமா?

ஆண் : அய்யோ - என்னை விடேன்.
