# அச்சு உரை

## அச்சிடப்பட்ட ஓடுதலைப்பு

கலைஞர் மு. கருணாநிதி

மட்டும் ரகசியமாக வந்துபோன விஷயம்,
ஒரு நாள் அம்பலத்திற்கு வரத்தான்
போகிறது! - நமக்குப் பிறக்கப் போகும்
“குழந்தை” உம்மைப் பார்த்து “அப்பா
அப்பா” என அழைக்கத்தான் போகிறது.
அப்போது ஊரார் கேட்பர், குழந்தையின்
தாய் யாரென்று! நீரும் சொல்வீர்;
தனிமையென்னும் தங்கக் கொடி பெற்ற
தளிர்க் கொடி; சிந்தனைச் செல்வம்;
கற்பனைக் களஞ்சியம் இதுவென்று!

ஆண் : சரி சொன்னால் சொல்கிறேன் - நீ போ!

பெண் : உண்மையைச் சொல்லும்! என்னைப்
       பிடிக்கவில்லையா?

ஆண் : உண்மையைச் சொல்லுகிறேன் -
      தெவிட்டுகிறது - சற்று விலகியிரு!

பெண் : முடியவே முடியாது!

ஆண் : நான் போகிறேன்.

பெண் : எங்கே போகிறீர்... சிறைக்கதவு வெளியே
       பூட்டியிருக்கிறது... கவனமிருக்கட்டும்.

ஆண் : தூங்கப் போகிறேன்.

பெண் : சரி - என் மடியில் சாய்ந்தபடி தூங்கும்.

ஆண் : அடா அடா அடா!......

பெண் : ஹி ஹி ஹி..... வெற்றி! வெற்றி!

●
