# தனிமை

<!-- source scan: 49 / printed page: 48 -->

பெண் : அன்புள்ள காதலரே!

ஆண் : யார்?

பெண் : யாரா? தெரியவில்லையா என்னை?
       உங்கள் திருமுகத்தைக் காண
       எவ்வளவு நேரமாய்க்
       காத்திருக்கிறேன்!

ஆண் : வாராதே என்று எத்தனை முறை
      சொல்வது?

பெண் : ஏன்... என்னைப் பிடிக்கவில்லையா?

ஆண் : ஆமாம்!

<!-- source scan: 50 / printed page: 49 -->

பெண் : உமக்கென்ன பைத்தியமா! நேற்று
       இரவெல்லாம் என்னை
       ஆரத்தழுவியபடியே கிடந்தீரே...

ஆண் : அதற்கென்ன இப்போது - நான்
      அழைத்தால் வா - போ!

பெண் : சரிதான். தேவைப்பட்டால் வரவேண்டிய
       தேவமாதுவா நான்!

ஆண் : தேவாமிர்தமாயிரேன் - இப்போது
      தேவையில்லை.

பெண் : அந்த அமிர்தத்தையும் தோற்கடிக்கும்
       என்றீர் என் அதரபானம்! கற்பனைகள்
       ஊறுகின்றன என்றீர் என் கன்னத்தைத்
       தடவியபடியே! காவிய மாளிகை
       எழுகின்றது எனக் கதைத்தீர் என் காந்தள்
       விரல்களை ஸ்பரிசித்தபடியே! கவிதை
       மழை கொட்டுகிறது எனப் போதை
       மொழியில் புகன்றீர் - கருத்துக் குவியலே!
       எண்ணப் புதையலே! கனியே! தேனே!
       வா; வா! என வாயார அழைத்து,
       அணைத்து, அமளியில் குலவினீர்! வேயா
       மாடத்தில் ஓயா இன்பம் பெறுவோம்
       என்றீர்! வேணு கானமோ - வீணை
       நாதமோ - என்று வர்ணித்தீர். அப்படி யெல்லாம்
       புகழாரங்கள் பூட்டிய நீரா இன்று
       அதிகாரத்துடன் விரட்டுகிறீர்?
       காதலரே எல்லாம்.... எல்லாம்
       கட்டிலறைப் பேச்சுத்தானா?

<!-- source scan: 51 / printed page: 50 -->

ஆண் : கட்டிலறைக்கா வந்திருக்கிறாய்; கண்
      உதிர்ந்தவளே! நன்றாகப் பார்! இது
      கட்டிலறையா? காராக்கிரகத்தின்
      காவலறையடி!

பெண் : ஆமாம் - இந்த அறையில் என்னைத் தவிர
       உமக்கு இன்பமான பொருள் எது துரையே!
       வாரும், சினம் கொண்ட பாம்புகள் போல்
       பின்னிக் கொள்வோம்... ஏன் தயக்கம்?

ஆண் : பேசாதே!

பெண் : கனியே வருகிறது - சுவைத்திட
       மறுக்கிறீர். மலரே வருகிறது -
       முகர்ந்திடேன் என்கிறீர். இன்பமே
       வருகிறது- எட்டி நில் என்கிறீர். நீர்
       அதிசயமான கள்ளை - புதுமையான
       வண்டு - விசித்திரமான மனிதர்.

ஆண் : இப்போது நீ என்னதான் சொல்கிறாய்?

பெண் : எதைச் சொன்னால் நீர் ஆசையோடு
       கேட்பீர்?.... “சங்கத் மொழி பேசும் உம்
       குழந்தைச் செல்வங்கள், ‘அப்பா எப்ப
       வரும் ஆத்தா?’ என்று உமது தாயாரிடம்
       சிணுங்கி அழுவார்களே; அதைச்
       சொல்லவா?

ஆண் : அய்யோ - போதும் நிறுத்து!

பெண் : தலையணையைக் கண்ணீரால்
       குளிப்பாட்டும் உம் மனைவியின்

<!-- source scan: 52 / printed page: 51 -->

நிலையைச் சொல்லவா? அதைக்
கேட்பீரா?

ஆண் : வேண்டாமடி, வேண்டாம்!

பெண் : பிறகென்ன, பழைய நினைவுகளைச்
       சொல்லட்டுமா? மரணப்படுக்கையில்
       உமது முதல் மனைவி பத்மாவதி -
       ‘கடைசி யாகத் துடிக்கும் என் உதட்டில்
       ஒரு முத்தங்கள் கொடுங்கள் தான்” என்று
       கேட்பதற்கு முன் பெற்றுக்கொண்டாளே....

       அதை....

ஆண் : அய்யோ... வேண்டாம்.... நீ போயேன்!

பெண் : உமது குடும்பத்தார் - தாய், மனைவி,
       சகோதரிகள்.... குழந்தைகள்... உழுவலன்பு
       பூண்ட நண்பர்கள்... உமது நலமே தன்னல
       மாய்க் கொண்டிருந்த தந்தை.....

ஆண் : சொன்னால் கேள்! போதும் நிறுத்து!

பெண் : இதெல்லாம் பிடிக்காவிட்டால் உமக்கு
       மிகவும் இனிப்பான சேதி சொல்லுகிறேன்;
       இந்த நாடு இருக்கிறதே - இது ஒரு
       அடிமை பூமி. இதை விடுவிக்க
       உண்மையான தொண்டர்களும்,
       நேர்மையான தலைவர்களும் எத்தனை
       பேர் வேண்டும் தெரியுமா?

ஆண் : அய்யோ - என்னை விடேன்.

<!-- source scan: 53 / printed page: 52 -->

பெண் : முடியாது - இந்த முத்தங்களைப் பெற்றுக்
       கொள்ளும்.

ஆண் : விடு என்னை - உன் கரம் அக்கினிக்
      கட்டையாயிருக்கிறது! உன் முத்தம்
      முள்ளாகக் குத்துகிறது.

பெண் : நேற்று?

ஆண் : அதை மறந்துவிட்டேன்.

பெண் : போன வாரம்?

ஆண் : அதையும் மறந்துவிட்டேன்...

பெண் : போன மாதம்.....?

ஆண் : எல்லாவற்றையுந்தான்! தயவுசெய்து நீயும்
      மறந்து தொலைந்து போ!

பெண் : அய்யா கோவலரே! நாம் இருவரும் மறந்து
       விடலாம். ஆனால் என் வயிற்றிலே
       வளரும் ஒவியத்தை யார் மறப்பது! அது
       நம் உறவை வெளியிலே சொல்லித் தான்
       தீரும்! பல இரவுகள் - பல பகல்கள்
       நாம் பாடிய காதல் கீதத்தின் அற்புதமான
       அடையாளம் அடியாளின் வயிற்றில்
       வளருகிறது கண்ணாளரே! மறக்க
       முடியாது அதை! மறுக்கவும் முடியாது நீர்!
       உலகம் சொல்லத்தான் போகிறது அந்த
       உண்மையை! எந்த வசதியும் நுழையக்
       கூடாதென்று தடை போட்டுள்ள சிறைச்
       சாலைக்குள்ளே உம்மிடம் ஒரு பெண்

<!-- source scan: 54 / printed page: 53 -->

மட்டும் ரகசியமாக வந்துபோன விஷயம்,
ஒரு நாள் அம்பலத்திற்கு வரத்தான்
போகிறது! - நமக்குப் பிறக்கப் போகும்
“குழந்தை” உம்மைப் பார்த்து “அப்பா
அப்பா” என அழைக்கத்தான் போகிறது.
அப்போது ஊரார் கேட்பர், குழந்தையின்
தாய் யாரென்று! நீரும் சொல்வீர்;
தனிமையென்னும் தங்கக் கொடி பெற்ற
தளிர்க் கொடி; சிந்தனைச் செல்வம்;
கற்பனைக் களஞ்சியம் இதுவென்று!

ஆண் : சரி சொன்னால் சொல்கிறேன் - நீ போ!

பெண் : உண்மையைச் சொல்லும்! என்னைப்
       பிடிக்கவில்லையா?

ஆண் : உண்மையைச் சொல்லுகிறேன் -
      தெவிட்டுகிறது - சற்று விலகியிரு!

பெண் : முடியவே முடியாது!

ஆண் : நான் போகிறேன்.

பெண் : எங்கே போகிறீர்... சிறைக்கதவு வெளியே
       பூட்டியிருக்கிறது... கவனமிருக்கட்டும்.

ஆண் : தூங்கப் போகிறேன்.

பெண் : சரி - என் மடியில் சாய்ந்தபடி தூங்கும்.

ஆண் : அடா அடா அடா!......

பெண் : ஹி ஹி ஹி..... வெற்றி! வெற்றி!

●
