# ஆண்டு விழா

<!-- source scan: 129 / printed page: 128 -->

அவள் : “கிளியென்னைத் தனிவிடுத்துப் புலி
வேட்டையாடுதற்குப் போகின்ற
அத்தானே! துளிக்கூட இரக்கமில்லை
உந்தன் நெஞ்சில் ?”

அவன் : “உளிப்படா உயிர்ச் சிலையே! ஒளி
விளக்கே! விடுபட்டிருக்கின்ற
அம்புக்கெல்லாம் வேலை தரக் காடு
செல்வேன்; விடை கொடு - விரைவில்
வருவேன்.”

<!-- source scan: 130 / printed page: 129 -->

அவள் : “அம்பென்றாய் அன்றொரு நாள் எந்தன்
கண்ணை - இக்கணையைத்
தூங்கவிட்டு அக்கணைக்கு வேலை தர
அடவிப் பயணம் - அடுக்குமா அத்தான்
இது ?”

அவன் : “வக்கணைக்காரி! இக்கணமே இந்தா
முத்தம்; எண்ணிக்கொள் - இந்தப்
பேச்சுக்கு எந்தன் பரிசு!”

அவள் : “முத்தத்தால் முழு உடலும் கொதிப்பேறி
இதயத்தின் எக்கமிகு சத்தத்தால் எந்தன்
காதெல்லாம் செவிடுபடும் செயல் புரிந்து
செல்லாதே வேண்டாம்; என்னைத்
தீண்டிக் குளிரேற்றிப் பின்னர் நடுங்கும்
உடலுக்குப் போர்வையாய் உதவாமல்
போய் விடுவாய் - வேண்டாம்;
வேண்டாம்!”

அவன் : “திங்களியே! தீண்டுவதால் குளிர்
என்றாய்; முன்பு தீப்போல்
கொதிக்குமென்றாய் உந்தன் மேனி -
இதில் எதை நான் நம்புவது ?”

அவள் : “குளிர் பொழிகின்ற நிலவினுக்கும்
வெப்பமுண்டாம் - அதுதான் குறள்
முழக்கும் மூன்றாம் பாலினுக்கும் முழு
பொருத்தம்!”

அவன் : “உன்னைக் கைப்பிடித்து ஒரு கிழமை
ஊமையாய்க் கிடந்தாய் - ஆண்டு ஒன்று

<!-- source scan: 131 / printed page: 130 -->

முடிவதற்குள் அனைத்துலகும் வெற்றி
கொள்ளும் கனிப் பேச்சு
கொட்டுகின்றாய்!”

அவள் : “இன்னும் என்னை ஊமையாய்ச்
செய்வதற்கு ஒரு வழி உண்டத்தான்...”

அவன் : “என்ன கண்ணே ?”

அவள் : “பேச்சற்ற உலகம் ஒன்று; ஆண்டவனால்
அமைவதில்லை அவ்வுலகு; ஆண்
பெண் இருவருமே படைக்கின்ற புது
உலகு - போவோமா ?”

அவன் : “விழியம்பு காட்டி, வில் புருவம்
வளைத்துக் காட்டி, இதழோரம் அமுது
காட்டி, இன்பக் கரையோரம் நடப்பதற்கு
அழைக்கும் பாவாய் - இரு புலியைக்
கொன்று வந்தால் இறைவன் தரும்
பரிசுப் பொருள் இந்த வீட்டெல்லாம்
குவியும்! இரு, ஒரு நாள் தனியாக -
நாளை வருவேன்!”

அவள் : “தனியாக இருப்பதில்லை; கனியாமல்
காயாக வளர்ந்து வரும் அன்பின் சின்னம்
அடி வயிற்றில் விளையாடும் - அதன்
எழிலைக் காணாமல் நான் தவிப்பேன்
- ஆயினும் எல்லையில்லா
மகிழ்ச்சியோடு பிள்ளை தரும்
தொல்லையிலே இன்பம் காண்பேன்!

<!-- source scan: 132 / printed page: 131 -->

நீ அருகிருந்தால் உந்தன் கிள்ளை என்
வயிற்றுக்குள் ஆடுகின்ற ஆட்டந்தன்னை
நாம் இருவருமே சுவைக்கலாமே!”

அவன் : “சுவைப்பதற்கு அட்டியில்லை
சொன்னமே! புலி இரண்டு கொன்று
விட்டால் புவியாளும் சோழனுக்குப்
பெருங் களிப்பு! எனையாளும் உந்தன்
முத்தத்துக்குப் புலி நகத்தால் பொற்றாலி!
வரப்போகும் ‘புது வாழ்வு’ புலிப்பல்
நகையால் பொலிவு பெறும்!”

அவள் : “போகட்டும் - பொழுது போவதற்கும்
விடிவதற்கும் இடையிலே என்னோடு
இருந்துவிட்டுச் சேவலோடு எழுந்திருந்து
நடப்பதற்கும் மறுப்பு தானோ ?”

அவன் : “மறுப்பேது; பருப்பு நெய் பாகுந்தேனுங்
கலந்து தரும் உண்டுதனை வெறுப்பதற்கு
ஆளும் உண்டோ ? ஆயின் ஒன்று -
இரவோடு சென்றால்தான் ஒளிந்திருந்து
காட்டினிலே புலி பிடிக்க ஏதுவாகும்!”

அவள் : “சரியத்தான் சென்றுவா நீ - எரியெடுப்பாய்
எந்தன் மனந்தனை ஆக்கிவிட்டு ‘எலி’
பிடித்து வரப் போகின்றாய்; போ - போ
- உடன் போய்விடு!”

அவன் : “மின்னலுக்கு உவமையாகும் இடையழகி!
இடைதனிலே இயற்கைக் குடமேந்தி

<!-- source scan: 133 / printed page: 132 -->

நடக்கின்ற பாங்கு கண்டு இதயம்
தந்தேன். உன் தந்தை மணம்புரியப்
பொருத்தம் பார்த்தார். என்
மலைத்தோளில் உன் பழக்கன்னம்
பதிவதற்குப் பொருத்தமுண்டா ? அதைப்
பார்க்கவில்லை ஆரூடத்தில்!
தோஷமொன்று தொங்குவதால் ‘பிள்ளைப்
பேறு’ வாய்ப்பதற்கு இடமே இல்லை -
இதைச் சொன்ன நிமித்திகனை
இழுத்துரைத்துக் குடும்ப விளக்கை ஏற்றி
வைத்தோம் - இந்த ஆண்டில்,
இறுதியிலே குலக் கொடியைப் போற்றி
வளர்ப்போம்... இதற்கிடையே இன்னொரு
நாள் விலகியிருப்பதற்கு விடை
தருவாய்!”

அவள் : “ஒரு நாள் பிரிவதற்கு அழவில்லை;
கொடும் புலியின் பிடியில் பட்டால் அரும்
பொருளை இழந்து நிற்பேன்-ஆருயிரைப்
பறிகொடுப்பேன் அதனால்தான்
கெஞ்சுகிறேன் - ‘விஷப்பரீட்சை
வேண்டாமென்று!’”

அவன் : “அரசனது ஆண்டு விழா - அன்று
வேடிக்கை பார்ப்பதற்கு மட்டுமல்ல;
வெகுமானம் பெறுவதற்கும் போகலாம்
அன்பே!”

அவள் : “ஆண்டு விழா அரசனுக்கு இப்போது -
இந்நாளில் புலி வதைத்துப் பரிசு பெறத்

<!-- source scan: 134 / printed page: 133 -->

துடிக்கின்றாய் - பொன்னான
பரிசொன்று நான் தர இருக்கின்றேன்;
நாலு திங்கள் பொறுத்துக் கொள்வாய்!”

அவன் : “சின்ன மலர் - வண்ண மயில்-தமிழ்
மழலை - தங்கக் கட்டி -”

அவள் : “கன்னல் நிகர் செந்தமிழைக் கரத்தில்
ஏந்தி, எண்ணமெல்லாம் இனிப்பேறும்
உந்தன் முன்னே இதழ் முழுதும் சிரிப்பு
விளக்கேற்றி நின்றிடுவேன் - அதைவிடப்
புலி கொன்று பெறப் போகும் பெரும்
பரிசு சிறப்பானதோ ? செப்பிடுவாய்!”

அவன் : “கண்ணமுது காட்டுகின்ற என் அருமைத்
தங்கம்! கட்டழகும், நாம் பெற்ற
மொட்டழகும் இன்பம் எனினும்,
காட்டினிலே ஒளிந்திருந்து நாட்டழகைக்
கெடுக்கின்ற புலி கொல்லல்
பேரின்பமன்றோ!”

அவள் : “பல் வரிசை முத்தாரம் எனப் புகழ்வாயே;
அதைவிடப் படைவரிசை பெரிதாகி
விட்டதோ உனக்கு ?”

அவன் : “முத்தாரம் வேண்டாமெனச் சொல்ல
வில்லை; உன் முத்த ஆரத்தை
வெறுக்கின்ற துறவியுமல்ல; உனை
அடையாமல் இருந்தால் நான் எடுத்தது
பிறவியுமல்ல - எதற்கும் நேரம்
வேண்டும்; நிலையை உணர வேண்டும்

<!-- source scan: 135 / printed page: 134 -->

- முரசொலிக்கும் நேரம்; முதுகாட்டில்
புலியொழிக்க அணிவகுப்புக்
கிளம்புகின்ற வேளை - முத்தாரம்
கண்டுவிட்டு, முரசொலிக்கு
செவிமடுப்பேன் - நாடு காக்கும் நல்ல
செயல் முடிப்பேன் - செயல் முடித்த
பின்னர்; சிந்தைக்கு விருந்தாக முத்தாரம்
கொடுப்பேன் உனக்கு!”

அவள் : “அறிவு தெளிந்தத்தான் எனக்கு - நாடு
மக்களைக் கொன்றொழிக்கும் காட்டு
விலங்கழிக்கப் போவதுதான் தமிழ் மகன்
கடமை!... அதோ முரசு ஒலிக்கிறது -
புறப்பட்டு விரைவில்!”

அவன் : “அதை; வாயின் முத்தாரம் காட்டிச்
சொல்வாய்!”

●

வழியனுப்பி வைக்கிறாள்)
