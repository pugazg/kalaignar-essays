# கலைஞர் கட்டுரைகள் / ஆய்வுக் கட்டுரைகள் — மின்னாக்கக் களஞ்சியம்

கலைஞர் மு. கருணாநிதியின் கட்டுரைகள், தொடர்கட்டுரைகள், சிறுநூல்கள் மற்றும் பல கட்டுரைகள் அடங்கிய தொகுப்பு வெளியீடுகளை **மூல ஸ்கேனை controlling source ஆகக் கொண்டு** Markdown வடிவில் பாதுகாக்கும் களஞ்சியம்.

## மூலக் கொள்கை

> **மூல ஸ்கேன் தான் controlling source. Markdown ஒரு பாதுகாப்பு அடுக்கு; திருத்தப்பட்ட புதிய பதிப்பு அல்ல.**

மூலத்தில் தெரியும் எழுத்து, பழைய எழுத்துப்பாங்கு, punctuation, பெயர்கள், எண்கள், மீளுரைகள், வழக்கத்திற்கு மாறான இலக்கணம் ஆகியவை அமைதியாகச் சீர்திருத்தப்படவோ நவீனப்படுத்தப்படவோ கூடாது. Library stamp, handwriting, accession marks, bleed-through போன்ற physical-copy marks அச்சு உரையிலிருந்து தனியாகப் பதிவு செய்யப்படும்.

**மூல PDF கோப்புகள் repository-யில் commit செய்யப்படாது.**

7. **`விபீஷணருக்கு விடை யளிப்போம்!` → `Let Us Answer Vibhishana!`**

Publication-wide, `ஆச்சாரியார்` refers to **C. Rajagopalachari (Rajaji)** and is rendered **`Achariyar`** when that is Kalaignar's source label. Article 7 demonstrates the complementary rule: where Kalaignar explicitly writes `இராஜாஜி`, English preserves **Rajaji** instead of harmonising it back to Achariyar.

Article 7 preserves the repeated **Vibhishana / Vibhishana-ness / Vibhishana doctrine** polemic, **Sivagnanam / Sivagnanams** including the mocking plural, the **muppuri** sacred-thread image, source-bearing **thanda-kanda / Inithavayan / Argusis**, **tail-bearers**, **vow of one wife**, the **demonic frenzy of colour-hatred** phrase, the fox/heron/deer/fish analogy, and the closing **carrying kavadi for the North / Time alone must give the answer!** cadence. The difficult scan-48 source wording `கற்பு நிலையைப் பாதிக்கும்` is documented rather than silently normalised.
